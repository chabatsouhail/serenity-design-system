The Button has a measured anatomy diagram with Parts, Spacing, and Type & shape views, composition and size comparisons, a Variant/Style matrix, state and loading examples, a keyboard-operable configuration playground, generated HTML, and searchable Token mappings. Measurements are read from the production specimen; no Button state CSS is duplicated in the reference. The other 45 destinations use the shared component-reference renderer.
